# edtable

## Как запустить у себя

1. Забрать код

2. Создать виртуальное окружение

```bash
python -m venv .venv
```

3. Активировать его

```bash
.venv\Scripts\Activate.ps1
```

или: `source .venv/bin/activate`.

4. Поставить зависимости

```bash
pip install -r requirements.txt
```
